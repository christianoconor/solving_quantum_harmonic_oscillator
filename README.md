# solving_quantum_harmonic_oscillator
A finite-difference method for differential equation approximation was coded partially using generative AI. This method was used to approximate solutions to the time-independent Schrodinger equation. Afterwards, error analysis was conducted once the code was working as expected.

This was partly an exercise in understanding where the common pitfalls of using generative to assist in coding are. The project also furthered my understanding of approximation methods and scratched the surface of quantum harmonic oscillators - a topic I'm diving into this term in my Quantum Fields and Particles module.
